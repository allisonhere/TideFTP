the idea

A GUI email client's clarity — a unified inbox, an account picker, a reading pane that never hides your list — with a terminal client's speed and a keyboard that gets the good seat. Set it up by filling in a form, not editing TOML.

what it does

Built around a few real habits

The things you actually do with mail every day, made fast.

One screen

Every account, one view

Read a unified inbox, or open any single account, folder, or Gmail label — from the same three-pane screen.

The list never disappears

Accounts left, message list top-right, reading pane below it. Opening a message doesn't hide your inbox.

Send from the right addressCtrl+U

The From row is an account picker. TideMail switches the SMTP server, Drafts folder, From address and signature to match.

A few seconds to change your mind

UnsendCtrl+Z

A sent message waits five seconds by default. Ctrl+Z reopens it. Set the delay to 0 if you want mail gone at once.

Undo bulk actions

Delete, archive and move queue for six seconds before they reach the server. One Ctrl+Z puts the last batch back.

State belongs to the server

Read, star, archive, move and delete sync over IMAP. Changes made in Gmail or another client come back on the next sync.

Reading

HTML as clean terminal text

Mail renders to readable text and never loads remote images.

Unsubscribe without the huntCtrl+U

Uses the message's unsubscribe header or its labelled link — no scrolling to a 6px footer.

Headers when you want themCtrl+E

Full headers one keystroke away, with SPF, DKIM and DMARC results called out in colour.

Search that stays live/

Global search across the local cache, results navigable while the query stays active. Find-in-message, link-walking, visual copy, and save-attachments in the content pane.

Compose

Drafts save as you type

Under the selected sender account. Reopen one and the same account picker is there.

Contacts, then history

To/CC/BCC suggest saved contacts first, then addresses from mail you've synced. Contacts move through vCard files.

Your editor, your way

Shift-selection, system clipboard, undo/redo, word movement, Home/End — or switch on Vim mode for dw, dd, :w, :q.

Optional AI, off by default

Point it at OpenAI, Claude, Gemini or a local Ollama for summaries and a draft proofread — or to turn a plain-English rule into a local filter that runs with no AI call per message.

Setup & secrets

No config file editingM

Add incoming and outgoing settings in the app, save with Ctrl+S. Any IMAP/SMTP server works via the Custom provider.

OAuth where it matters

Gmail and Outlook sign in with OAuth. Outlook uses Thunderbird's shared public client — no setup. Gmail wants a free Google Cloud project you own.

Secrets in the keychain

Passwords, AI keys and OAuth refresh tokens go to libsecret on Linux or Keychain on macOS, with a documented config-file fallback.

Mail as it lands

IMAP IDLE by default, so messages arrive when the server announces them. Interval polling and manual-only modes are there for servers that need them.

install

Get it

Linux and macOS, Intel and ARM. The installer writes to ~/.local/bin — no system password.

One line

$ curl -fsSL https://raw.githubusercontent.com/allisonhere/tidemail/main/install.sh | sh

Then

$ tidemail
# press M, add your mail settings, Ctrl+S to save

Prefer an archive? Grab one from the latest release.

the honest part

Worth knowing

  • IMAP and SMTP only. Standard mail protocols — including on-prem Exchange that still speaks IMAP. No proprietary-only or EWS-only mailboxes.
  • Linux and macOS. No Windows build.
  • Gmail OAuth needs a project. TideMail ships no OAuth client, so a no-expiry Gmail token means creating a free Google Cloud project you own. Outlook needs nothing.
  • AI is bring-your-own-key, and stays off until you configure a provider.
