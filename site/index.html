the shared part

One set of habits

Learn the pattern once in any of them and the rest are already familiar.

j k Tab

Keyboard first

Move with j/k, cross panes with Tab, act with a single letter. The mouse works; you won't need it.

?

Help that's in the app

Press ? anywhere for a searchable keybinding reference. No man page, no wiki tab.

: Ctrl+K

A command palette

Forget a key? Type what you want to do and hit Enter.

T

Themes that stay readable

Nineteen palettes — Catppuccin, Nord, Gruvbox and more — with text and borders held to WCAG contrast minimums by automated tests, in every one.

local

Your data on your machine

Local caches, local config, secrets in the system keychain. Nothing phones home.

curl · sh

One-line install

A single script drops a binary in ~/.local/bin — no root, no package manager.

the four apps

Pick your job

Each is a standalone binary. Take one, take all four.

≈ TideTerminal Information Delivery Engine · instead of newsboat

A terminal RSS & Atom reader. The one that started the family — its three-pane layout and theme workflow became tideui.

  • Feeds, folders, and a unified unread view in one three-pane screen
  • Reading pane renders articles as clean terminal text
  • Keyboard-driven: j/k through items, o to open, ? for help
github.com/allisonhere/tide
≈ TideMailinstead of mutt / Thunderbird

A keyboard-first IMAP & SMTP client. Every account on one screen, all setup in the GUI — no config-file editing.

  • Unified inbox across accounts, or open any account, folder, or Gmail label
  • Ctrl+Z to unsend or undo a queued archive / move / delete within a few seconds
  • Ctrl+U to unsubscribe straight from the message header while reading
  • SPF / DKIM / DMARC results shown in colour; remote images never load
  • Optional AI (OpenAI, Claude, Gemini, Ollama) for summaries, proofreading, and plain-English filters — off until you configure it
$ curl -fsSL https://raw.githubusercontent.com/allisonhere/tidemail/main/install.sh | sh
github.com/allisonhere/tidemail
≈ TideFTPinstead of lftp / FileZilla

A file transfer client for SFTP, FTP and FTPS — FileZilla's two-pane layout with a real transfer queue, in the terminal.

  • Parallel transfer queue with per-file and overall ETA, retry and resume
  • Conflict policies: overwrite-if-newer / -different-size / resume / rename / skip, apply-to-all, remember
  • Directory mirror (M) with a new / updated / unchanged plan and opt-in prune
  • Streaming preview and in-place edit without downloading the whole file
  • Strict host-key checking; passwords never passed as flags
$ git clone https://github.com/allisonhere/TideFTP && cd TideFTP && go build ./cmd/tideftp
github.com/allisonhere/TideFTP
≈ WhatTheDockinstead of lazydocker / the Docker CLI

A terminal client for Docker containers and Compose stacks — local and remote hosts, in one place.

  • See what's running, tail colour-coded logs, start / stop / restart / recreate
  • Container Clipboard: y a container's config on one host, switch hosts, P to paste it
  • A Compose catalog you can keep, edit, annotate, and make live on any host
  • Create / edit form with a live-generated YAML preview
  • Opt-in AI analysis of a failing container from the Problems pane

the engine

tideui — the shared shell

tideui is the toolkit every app is built on: a themeable, multi-pane view layer for Bubble Tea and Lipgloss. It renders the pane shells, status bars, and modal overlays; each app keeps its own model, key routing, and state.

Five layout modes, nineteen palettes with per-field overrides, four-sided focus borders held to a 7:1 contrast floor, a VT52 ASCII mode, and output that never spills past the terminal's edges — down to tiny windows. It's why the four apps look and move alike.
